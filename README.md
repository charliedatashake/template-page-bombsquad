# Gabarit de page, Bomb Squad Paris

Maquette de travail datashake. Elle presente le gabarit de page a decliner sur les pages
d'occasion de paris.bombsquad.games, rendu dans la charte reelle du site.

Un bouton en haut a droite permet d'alterner entre la page nue et la page annotee.
Les annotations indiquent pour chaque bloc ce qui est deja en place, ce qui doit etre
renforce, ce qui est a creer, ce qui change d'une page a l'autre, et ce qui s'active
selon l'occasion.

Les textes sont des exemples destines a montrer le niveau de precision attendu,
pas une version validee.

Page non indexable (meta robots noindex).
